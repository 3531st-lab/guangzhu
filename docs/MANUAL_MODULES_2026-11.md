# 光伏组件手动编辑

打开本机设计结果，选择 **局部修改 → 手动组件**。支持在普通平屋顶、彩钢瓦及整栋多坡屋面上补放组件、移动所选组件、旋转所选组件。使用项目当前组件目录中的真实尺寸，保存为新的设计版本。

本机示例：[手动组件与区域锁 v6](http://127.0.0.1:8765/#result/manual-modules-demo?version=6)。这是带设备箱及分段女儿墙的合成屋顶，保留了遮挡和电气规则未通过的中间设计，用来展示修改的实际影响。

## 操作

| 操作 | 方法 |
| --- | --- |
| 补放 | 选择“补放组件”，点击“在平面图点选中心”，或填写中心 X/Y；选择横竖排、顺时针转角。多坡屋面必须选择所属安装面。十字只标出中心，点击“预览补放”后显示后端校验过的真实轮廓。 |
| 移动 | 点击平面图或三维组件切换选择，可选择多块；输入向东 ΔX、向北 ΔY，点击“预览移动”。各板保留编号和所属屋面。 |
| 旋转 | 选择组件，输入角度后预览。每块绕自己的中心旋转，正角为顺时针；不围绕整组选区中心公转。 |
| 查看影响 | 勾选“详细复算遮挡、发电、造价、回本和组串”。展示修改前后平均／最大遮挡损失、超阈值组件数、发电、造价、硬性规则及受影响组串；可展开逐组件遮挡变化。 |
| 保存 | 核对预览后“确认并保存新版本”。原版本及原分析文件保留。未勾选详细复算时，新版本明确显示待分析；不会借用旧版结果。 |
| 撤销 | 点击“预览撤销上次修改”，核对后确认。撤销恢复父版本的组件几何、锁定与相应规则状态，并另存新版本。 |

预览中，二维图区分新增、移动、旋转、原位置和删除；三维使用绿色新轮廓、橙色原位置及红色删除轮廓。候选不套用旧版遮挡热力、电气或风荷载；取消后恢复原方案。修改参数、选择或取消正在计算的预览，会使旧响应失效；保存期间禁用输入，防止重复确认。

## 几何与锁定

- 平屋顶组件旋转改变其朝向，保持真实长宽、倾角和支架下沿高度。彩钢瓦及坡屋面使用真实三维坡面内旋转，保持屋面法向；不会用二维旋转后贴面的方法拉伸板材。
- 移动坡面组件时，按所属坡面重新计算高度。跨屋脊或移到其他屋面会被拒绝；可在目标面另行补放。
- 屋边退距、设备和禁区避让、目录安装间隙、组件最高点以及已有锁定都经过后端验证。重叠、越界或锁定冲突会拒绝整次批量操作，不留下部分结果。
- 组件锁保护已有组件；区域锁和屋面锁同时保护其中的空白，不能向锁定空白补放或移入。选中锁定组件仍可用于显式解锁，但不能直接移动、旋转或删除。
- 新补放和调整后的组件不会自动锁定。需要保留在后续局部重排中的手工设计，应先锁定相应组件或区域。
- 零位移、0°／±360°等无变化操作不生成版本。老排布的毫米取整精度保留兼容来源；新补放组件之间不借用旧数据容差。

## 工程计算

直射遮挡沿用实际组件角点、屋面、设备、周边物和分段女儿墙的射线计算。手动散排不再沿用原来的规则排距估计天空遮挡，而使用实际场景、每板 9 个采样点与 128 个天空方向，按真实板面入射余弦加权。近邻板、设备和女儿墙均可影响结果；遮挡原因分别记录。

该天空积分采用等亮天空假设，并将可见度作用于原有 Perez 年天空散射量，属于近似；没有计算玻璃透射及地面反射遮挡。等亮天空的基本假设参见 [pvlib isotropic 模型说明](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.irradiance.isotropic.html)；旧规则行列模型的遮蔽角定义参见 [Passias 说明](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.shading.masking_angle_passias.html)。本项目的场景射线积分是本轮实现，不是对上述软件完整遮挡能力的复刻。

详细比较的前后版本使用同一种天空方法，但不改变原版本的几何、通道规则或结构状态。计算方法单独继承，因此撤销或完整重排恢复规则排布时，不会因保留天空算法而误将通道判成手动散排。

平屋顶冬至互遮挡检查按真实几何、每 5 分钟与每板 9 点采样，不以旧行号推断。结构分区荷载使用真实投影，DXF 使用实际角点。旋转导致不同倾角／朝向组时，电气和发电按对应组重新计算；如果新方位没有离线 PVGIS 数据，会明确列为缺失，不代入旧方位数据。

## 当前边界

- 手动编辑目前支持屋顶单排支架。地面桩基、车棚、东西向成对支架及一架多排组件仍需整体结构联动，界面会说明暂不支持自由单板编辑。
- 手动散排的连续检修通道尚不能自动证明。若用户明确设置了通道最小宽度，G03 会显示未通过、需按实际通行路径核对；不会取消要求或将其当作不适用。完整重排或撤销回原规则几何后，恢复相应自动检查。
- 发电与遮挡为现有天气和设计假设下的初步估算。计算完成不等于规则通过；保存草案也不等于获得导出批准。
- 手动入口使用本机设计编辑 API；现有智能体工具继续沿用保锁修改约束，不能解锁或撤销人工操作。
