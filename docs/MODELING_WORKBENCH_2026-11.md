# 精确建模工作台

本轮沿用光筑的屋顶参数模型，完善“选中对象 → 精确修改 → 多视图检查 → 保存 → 光伏复算”的操作流程。入口为首页 **＋ 新建安装面（画图或导入图纸）**，或“我的屋顶”中的 **编辑这个屋顶**。

## 对象选择与精确变换

**建模对象** 按建筑部分、屋面设备、禁区与采光带、周边遮挡、电气位置列出对象。单击列表或画布选中；按住 Ctrl／⌘ 单击可多选设备、禁区和周边对象。**定位对象** 缩放到选中几何，**更多属性** 跳转到对象参数。选择和视图操作不会让模型变为未保存。

设备、禁区及周边多边形可使用 **精确变换**：

- 相对移动：输入向东 ΔX、向北 ΔY。
- 绕点旋转：输入逆时针角度及旋转中心 X/Y，多选时默认围绕整体包围框中心。
- 左右／上下镜像：输入明确的轴线 X 或 Y。
- 勾选 **保留原对象，生成副本** 进行偏移复制或镜像复制，副本使用独立编号。并网点保持唯一，不能复制。

点击 **预览变换** 在二维查看虚线位置；取消预览不会写入模型，**应用变换** 后可一步撤销。更改选择、对象或变换参数后须重新预览，不能应用过期位置。保存仍检查设备是否落在屋面内、坡面归属及其他原有工程约束。建筑部分本轮继续通过原有位置、尺寸和檐口等参数修改，不参与设备组的自由变换。

## 标准三维视图

切换 **三维建筑**，使用工具条中的轴测、俯视、北／东／南／西视图，以及 **透视／正交** 选项。标准立面从对应方向看向建筑；正交模式保持相同尺寸的物体在不同深度具有相同显示比例。

**适合全部** 根据屋面、内部屋脊、女儿墙和屋面设备的实际三维范围构图，空组件的高屋脊不会被忽略。**定位选中** 可查看选定设备或建筑部分。投影切换、窗口缩放和选择不会改变模型坐标。

## 女儿墙分段

在右侧 **女儿墙分段** 中选择：

- **全周统一**：沿用原来的“女儿墙高度”，旧屋顶不需要迁移。
- **分段编辑**：按当前外轮廓生成各边，分别设置外墙边、距边首的起点和终点、高度；可删除一段、缩短形成缺口，或在缺口处添加新段。
- **无女儿墙**：显式清空墙段。即使原全周高度仍为 1 m，也不会生成墙。

距离以米为单位，是沿轮廓边的二维投影长度。高度为实际屋面之上的垂直高度，范围为 0–3 m；高度 0 不生成墙面。墙底随单坡、双坡和高低跨屋面变化，跨屋脊处分成真实坡面片段，不用一张平面跨过屋脊或高差。

二维橙色边线标出有效墙段。重叠、反向区间、越界与无效边号不能保存。改动屋顶轮廓后，旧边号可能不再对应原边；编辑器会要求 **按当前轮廓重新生成** 并重新校对，或恢复全周模式。未标定图纸须先确定比例尺。

分段参数随草稿、撤销、保存和重新打开保留，并进入新方案的锁定几何签名。老屋顶没有新字段时，其序列化与既有锁定签名保持兼容。

## 工程联动与边界

- 分段墙真实参与屋面遮挡计算；保存建模参数后，须对新的设计版本执行分析，已有版本的发电量和规则结果不会自动成为新几何的结果。
- 分段墙可能有缺口或不同高度，“不高出女儿墙”不能自动推算为一个全屋数值。条件表会提示手动核对并填写 **组件最高点**，不再借用旧全周高度。
- 园区中作为周边遮挡的邻栋仍采用既有保守外包络；分段墙取最高墙段加入邻栋包络，缺口不会被精确表达。单栋屋面内的分段墙遮挡使用精确墙面。
- 旧式“把双坡拆成两个屋顶”不能直接继承原轮廓边号；有非空分段时明确拒绝，应使用整栋坡面建模。
- 门窗、雨棚等上一轮的厂房装饰仍为外观示意，不加入结构、造价或遮挡计算。分段女儿墙只增加几何及遮挡定义，没有新增墙体承重、抗风或构造设计能力。
- 本轮不包含 LiDAR／照片自动重建、自由曲面、布尔开洞、BIM/IFC 双向交换或三维拖拽约束求解。
