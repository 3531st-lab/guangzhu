# 厂房三维外观

从首页点击 **＋ 新建安装面（画图或导入图纸）**，或编辑已有屋顶。展开 **厂房外观**，切换左侧 **三维建筑**，即可边修改边查看建筑细节。点击 **查看主立面**，镜头会转到所选外墙，便于检查门窗与雨棚。适用于平屋顶、彩钢瓦及平顶／双坡组合厂房。

## 可以调整的内容

| 内容 | 操作 |
| --- | --- |
| 整体配色 | 使用银灰、暖白、红砖预设，或分别修改墙面、立柱／收边、勒脚与门体颜色 |
| 墙面材质 | 金属压型板、混凝土板、砖墙 |
| 立柱和勒脚 | 调整柱距与勒脚高度，立柱可单独关闭 |
| 窗带 | 关闭或设置一／两排，调整单窗宽度、高度及首排窗台高度 |
| 主立面 | 自动选择最长外墙，或按朝向和墙长指定外墙边 |
| 入口 | 设置卷帘门数量、宽度和高度，启用／关闭人行门 |
| 雨棚 | 调整出挑距离；设为 0 关闭 |
| 装卸口 | 设置数量和装卸台高度，查看平台、门体及防撞细节 |
| 整体显隐 | 关闭“显示建筑细节”查看原建筑体块，或一键恢复默认外观 |

细节根据实际外墙分段布置。短墙、低墙和高低跨接缝处会适配或略去放不下的门窗；三维预览文字显示实际生成数量。主立面边失效时恢复自动选择并显示提示。

只改外观时保留当前观察视角。设置参与草稿、撤销／重做和屋顶保存；重新打开已保存屋顶时恢复。原来没有外观设置的厂房使用默认工业外观。

## 使用边界

门窗、雨棚与装卸平台是建筑外观示意，并非来自实测图纸的自动识别，也不表示结构构造已经核定。这些细节不计入光伏遮挡、结构、发电和造价校核；光伏工程仍使用已验证的屋顶、障碍物及组件几何。

外观修改不会移动已锁定组件，也不会改变锁定几何签名。改变实际屋顶高度、坡面或组件规格，仍须按原锁定规则处理。
