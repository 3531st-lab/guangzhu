# Antigravity 改动审查与三赛改进建议

审查日期：2026-11-04。对象是当前工作区及 Antigravity 的功能自述。基线 `66ed065` 后混有此前 Codex 的未提交改动，不能将整个工作区差异归给 Antigravity。本次通过新增入口、任务记录、源码和隔离复现确定范围；未修改产品源码、正式测试或真实项目。

## 总体判断

本轮增加了自动设计和快捷修改入口、报告与下载入口、设备目录、泰州场景和园区展示，产品演示的覆盖面有所扩展。但新增路径存在启动阻断、旧项目被删除、报告版本混用、审核标签失真及电缆错误计算，当前版本不适合作为稳定路演版或可信工程交付版。

新增免 Key 路径主要是确定性工程自动化：直接调用现有计算函数，Copilot 使用关键词和正则表达式。它具有自动化价值，但源码没有显示这个路径具备四个实际 Agent 调度或独立模型审核。原有 AGH 模型路径仍存在，应与新增规则流程分别表述。

Antigravity 自述中的“一等奖 91%/93%/94%”“综合获奖 96%–98%”没有可验证的统计依据，应撤回，不能据此决定备赛投入。它还错误描述了本届蜂鸟奖项和奖金。

铝缆反例的具体结果：当前代码为 `YJLH22-4x120` 给出 268A、压降 1.773%、合格；本仓新增目录对该型号给出 210A，以目录电阻参数代入同一公式得到压降 2.880%。这已是内部数据矛盾，不依赖外部规范结论。

## 需要同时纠正的展示文案

- “四智能体协同”“自主推理链”“独立工程审核签章”：新增免 Key 路径没有对应执行证据。建议分别称为工程自动化步骤、规则指令解析和规则预检查；真正 AGH 运行展示其实际会话、工具调用、版本及审核来源。
- “4 人×3 天、8000 元 → 1 人×3 秒、效率提升 99.6%”：目前是硬编码文案，未见同条件计时与成本对照。删除固定成效值，评测后展示样本数、总耗时、人工复核与失败重做成本。
- “100% 本地离线”：缓存缺失时有在线天气回退。分别说明已缓存场景和首次新地点运行条件。
- “18 页”“设计院级”“施工图交付”“22 条国标全部通过”：章节数不等于打印页数，已有部分规则检查也不等于完整工程审查。按实际内容标注方案报告、布置图和已实现规则检查，并显式列出未核实输入与待专业复核事项。
- “泰州真实标杆工程”：在本轮查看的数据中仍有示意假设、未核实承载力和接网条件。地域命名和场景模板不能作为客户落地证明；没有测绘、授权和使用证据时标为“泰州产业场景演示”。
- 本届蜂鸟是第 1–10 名补助，第一名 2 万元，原件没有“一等奖 5 万元”这一口径。OPC 的“最高 50 万元落地资助”等附加权益未从本次原件研究获得支持，不应作为确定奖金宣传。

## 三项比赛目前能怎样判断

以下是依据项目现状与官方要求作出的产品判断，不是概率、分数或官方评审结论；以实际参赛者符合资格为前提。

| 赛事 | 当前判断 | 最值得投入的证据 |
| --- | --- | --- |
| 江苏创青春“AI+住房城乡建设” | 与开放赛道“产业发展”的智能设计、绿色低碳方向匹配直接；当前工程可信度问题会削弱技术论证 | 同一屋顶与相同输入下的公平工具/人工对照、独立工程复核、真实使用成效 |
| 泰州“全球通”杯 OPC | 行业轻量智能体方向适配；当前新增免 Key 流程的“四 Agent”说法不成立，应讲清模型与规则各自贡献 | 普通设备部署、真实模型工具轨迹、总交付成本、泰州重复业务及个人/小团队交付记录 |
| 第十二届蜂鸟 | 有技术产品基础；在本次材料中，客户需求、定价验证和在泰经营证据比功能展示薄弱 | 目标客户访谈、试用反馈、真实付费或意向证据、交付周期和在泰落地计划；没有交易不得补造 |

当前无法可靠估计任意奖、一等奖或第一名的百分比。缺少有效报名数、对手质量、完整评分量表、部分奖项名额与可校准历史样本；本项目也缺少稳定提交版本的独立验证。OPC 原文“20 支复赛”与两组共 30 个奖项存在未解释口径，不能直接计算获奖比例。名额/人数即使取得，也只表示总体席位比例，不等于本项目获奖概率。

修复软件错误能降低演示和结果失真的风险；真实试用、独立复核和公平对照能加强参赛材料。它们都不能据此换算成新的 90% 或其他确定胜率。

## 本次验证及边界

- 当前 Node 套件：246 通过、17 跳过、0 失败。它没有覆盖完整应用启动及这些新增分支，不能用此数字证明本版本可演示。
- Edge 真实页面在 1600×1000 下加载已有结果路由，出现模块语法错误并停在导航外壳。静态资源 HTTP 无失败；没有进入后续编辑/结果交互。显式 ESM 解析也失败。普通 `node --check file.js` 返回 0 在这里是误导性信号。
- 后端复现使用隔离临时项目。删除和下载错误走真实 API；报告版本问题拦截了最后 HTML 渲染，证明传入渲染器的上下文混版本，并未将完整 HTML 当作复现证据。默认 `verification.passed=true` 不代表最终报告审核栏显示通过；该栏仍因缺少审核核验数据显示未核对。
- 自动审核/导出决策的复现替换了天气和物理计算并拦截导出副作用，保留真实审核写盘，证明错误审核标签及导出调用决策，不代表生成了有效工程 CAD。
- 电缆、品牌、组件模型及图表使用真实相关函数的隔离复现；凹屋顶通道用实际动作分支、几何交集和正式模型校验。
- 本次没有跑全仓 Python 测试、真实模型调用或真实工程验收，没有发送材料、报名或联系客户。
