# 光筑参赛改进：2026 年 11 月

依据聊天「评估光筑参赛资格与获奖概率」最后确定的首批范围实施：**平顶／双坡组合建模、精确尺寸与阵列、区域锁定后局部重排**。改动在源码工作台中生效，既有 v0.2.0 下载包不会自动包含本次改动。

按后续要求追加 [厂房三维外观](FACTORY_FACADE_2026-11.md)：墙面材质与配色、立柱和勒脚、窗带、门、雨棚及装卸口，可在编辑器实时调整并保存。

## 本次可以直接操作的功能

| 评估要求 | 实现与入口 |
| --- | --- |
| 主厂房＋低跨附楼 | 新建／编辑屋顶 → 组合屋顶。各部分独立设置长宽、位置、转角、檐口高度、坡度、材料和承重来源。平顶与双坡可组合成连通的 L/T 形屋顶。 |
| 高差和屋面设备 | 部件之间显式生成高低跨墙并参与遮挡计算；同一屋面内仍执行原来的 2 厘米接缝检查。设备自动归属坡面，调整高度后同步；跨越不兼容屋面的设备会被拒绝保存。天窗／禁区可指定所属坡面，未指定时可跨面裁切。 |
| 二维／三维联动 | 编辑器切换三维预览后，参数修改更新真实几何；点击屋面定位并高亮所属部分。 |
| 精确操作 | 展开设备／天窗的精确编辑，输入位置、长宽和旋转角；设置阵列总数、间距与方向，先预览再应用，一次撤销整组阵列。端点／中点／边线吸附可独立开关。 |
| 保留人工设计 | 设计结果 → 局部修改。点选组件、选择坡面或输入矩形范围，预览锁定；锁定同时约束界面与 MCP 调用。区域锁会保留原有空白，不允许重排填入。 |
| 修改预览与确认 | 调整横竖排、屋边退距、通道排数与宽度后预览。显示新增、删除及装机变化；可勾选使用现有天气复算发电、造价、回本、硬性规则和受影响组串。确认后保存新版本。 |
| 取消与撤销 | 取消预览不保存。预览过期、项目变更或版本前进时，确认会被拒绝。用户可预览撤销上次修改，再确认生成恢复版本；旧记录不覆盖。 |
| 智能体约束 | AI不能解锁或撤销人工操作；全屋再生成也须保留锁定。资料与工程条件不足时，不把取消装机下限、零组件或未经复算的调整方向称为已可行方案。 |

## 打开和演示

本次已在项目目录创建独立 Python 3.12 环境并安装锁定依赖。双击根目录 `start.cmd`，会先检查依赖，然后打开桌面工作台。也可用以下命令启动本机网页：

```powershell
.\.venv\Scripts\python.exe -m uvicorn guangzhu.api:app --host 127.0.0.1 --port 8765
```

在首页选择 **高低跨组合厂房（示意）**，可编辑主厂房、附楼、6 个采光带和附楼机房。该案例使用合成尺寸、示意承重和常州天气快照，不代表客户项目或泰州实测案例。

生成可重复演示的本机版本链，不调用模型：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/competition_demo.py --project my-compound-demo --analyze
```

命令拒绝覆盖已有项目。它依次生成初稿、锁定一个主楼坡面、横排其余区域、重新计算并保留规则反馈和修正版本。结果在 `output/competition-upgrade/my-compound-demo.json`，包含版本、实际规则结果、设计文件摘要和本机访问地址。`analysis_complete` 仅表示计算完成，是否通过须查看 `analysis.rules.hard_failed`。

建议现场演示顺序：修改主楼与附楼高度 → 三维观察高差 → 预览六天窗阵列 → 打开方案 → 锁定主楼一侧 → 改其余区域排布 → 对比改动 → 确认新版本 → 展示规则与撤销。

## 适用范围

- 本版组合屋面采用各面顺面安装：平顶附楼为 0°，双坡部分跟随实际坡度；没有新增平顶附楼独立倾斜支架参数。
- 多个部分须通过边相连，轮廓不重叠且合并后无内孔；分离建筑应继续使用园区功能。
- 保锁重排复用现有确定性排布候选，不承诺全局最优。地面／车棚的结构联动保锁重排暂不支持，带锁全屋三方案搜索会明确拒绝。
- 已有锁定时，屋顶高度、坡面几何、组件与支架规格不能覆盖修改，须先由用户解锁；承重与经济输入仍可更新后复算。
- 详细预览使用本机已有天气。资料缺失或计算失败时明确显示“未完成”，不会沿用旧版本发电、造价或回本。保存草案不等于通过校核、独立审核或获得导出批准。
- AGH 自动设计与独立审核仍需要已配置的官方运行环境和模型账号；本轮离线测试不代表新的真实智能体任务达标率。
