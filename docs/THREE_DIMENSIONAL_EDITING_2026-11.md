## 打开示例

双击仓库根目录 `start.cmd` 启动源码工作台，再打开[本机三维操作示例 v10](http://127.0.0.1:8765/#result/direct-manipulation-demo?version=10)。该链接依赖本机已有的 `direct-manipulation-demo` 项目与 8765 端口服务；它是合成尺寸、示意承重的功能示例，仍保留 S01 遮挡超限，便于查看问题定位。

其他环境可先启动源码服务，再用全新的项目编号和输出文件建立同样的版本链：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/manual_modules_demo.py --project my-direct-example --output output/direct-manipulation/my-base.json
.\.venv\Scripts\python.exe -X utf8 scripts/direct_manipulation_demo.py --project my-direct-example --output output/direct-manipulation/my-roundtrip.json
```

第一条生成 v1–v6，第二条通过真实本机 HTTP 执行移动、撤销、旋转、撤销，到达 v10；脚本不调用模型。已有项目或输出会被拒绝，第二条仅接受停在 v6 的合成示例。完成后打开 `http://127.0.0.1:8765/#result/my-direct-example?version=10`。

## 直接移动与旋转

1. 在结果页进入“局部修改”。保持“浏览”，点击三维组件或组件选择平面图来切换选择，可选多块；绿色为选中，金色为锁定。先清除选中的锁定组件，或另行预览并确认解锁。
2. 在“三维直接编辑”选择“移动”，拖动已选组件；选择“旋转”，拖动出现的旋转环。多选移动使用相同水平位移；多选旋转时每块板绕自身中心转动。
3. 默认启用 0.1 m 网格、邻板对齐和 15° 角度吸附。可修改“网格间距 / m”“角度吸附 / °”，也可取消“吸附”或“邻板对齐”。拖动时按住 **Alt** 临时绕过吸附。
4. 需要工程比较时，先勾选“详细复算遮挡、发电、造价、回本和组串”。拖动期间查看候选轮廓、位移或角度与参考线；旧版年度遮挡、风荷载和电气卡片暂时隐藏。
5. 松开鼠标后自动发出一次预览请求。核对候选几何、保留的锁定对象及详细复算结果，再点“确认并保存新版本”。几何或锁区校验失败会显示具体原因，不生成版本。
6. 拖动中按 **Esc** 可取消；失焦、指针取消、切换工具或离开页面也会结束手势。已经生成候选时点“取消预览”；计算中可点“取消这次预览”。取消后旧响应不会重新显示候选或保存版本。
7. 保存后如需恢复，点“预览撤销上次修改”，检查恢复内容后再次确认保存。撤销会追加一个恢复版本，旧设计及其记录保留。切回“浏览”可继续调整视角。

## 问题定位与修复预览

在“规则”页签的“问题定位”中查看失败值、限值、对象证据与依据。“定位”只改变聚焦对象和显示模式，保留已有编辑选择；“进入局部修改”选择可编辑的相关组件。当前可定位有完整证据的 S01 单板遮挡、E08 未接线组件、E10 电缆路径／压降及 L01 坡面荷载问题。

S01 可提供“预览移除…块未锁定超阈值组件”。点击后进行详细复算，保留锁定对象，并由用户确认才保存。减少遮挡组件可能引出装机或组串问题，预览不承诺全部规则通过。其他问题仍按其证据和建议人工调整；缺少逐对象证据时说明无法定位，不猜测对象。

## 查看版本证据

进入“文件”页签，查看“版本证据”，或点击“下载证据 JSON”。证据卡显示保存版本的组件数量、输入假设、计算与规则状态、天气来源、审核记录、交付清单和文件 SHA-256；未保存候选不会替代这份证据。

新综合计算会校验设计与工程输入签名，并在全部六份分析文件写完后发布完成清单。输入变化、文件被修改、中断写入或并发混写导致不一致时，证据标为需要重算，并禁用基于旧结果的诊断修复。历史记录缺少签名或完成清单时明确显示“未记录”，不补造完整性证明。

输入签名覆盖项目模型内的工程参数，并另行绑定设计文件；外部目录 CSV、计算代码版本和天气缓存原始字节不在此签名中，完成清单不构成完整运行环境的可复现证明。

脱敏归档的原始导出摘要与当前快照摘要分别显示；快照通过归档核验不等于原始导出字节相同。同版本审核文件不单独证明审核会话独立，文件清单也不代替导出批准。会话用量可能覆盖多个版本，缺失费用、人工工时、失败与重试总数保持未知；会话时长不作为人工成本。

## 交互与边界

选择局部修改后，在浏览、移动、旋转之间切换。浏览保留原有视角控制；移动可拖动选中的组件；旋转使用可见圆环。支持多选，移动使用同一水平位移，旋转沿用已有后端“每板绕自身中心”的语义。普通平屋顶改变方位；金属和多坡屋面在真实坡面内旋转。跨所属坡面仍由后端拒绝。

默认启用 0.1 m 网格、邻板中心和边线（含目录安装间隙）对齐以及 15° 角度吸附。可调整步长、关闭吸附；Alt 临时关闭。操作过程中显示几何轮廓、数值和参考线，年度遮挡、风荷载和电气结果暂时隐藏。目录真实尺寸、安装间隙和支架偏移由后端提供，缺少完整模型的记录不可启用近似拖拽。

松手后只发出一次后端预览请求。预览通过后，用户确认才生成新版本；详细预览可复算前后遮挡、发电、造价和组串。失败回到保存版本并显示具体原因。锁定组件不能拖动，锁定区域内的空白也不能被占用。Esc、指针取消、失焦、切换模式或页面会取消手势；取消预览和过期响应均不产生版本。撤销沿用真实父版本恢复契约。

- 三维直接组件操作支持普通平顶、彩钢瓦和多坡屋面；空地、车棚、东西向成对排布及一架多排组件暂不支持这组手动几何操作。仍可使用其已有锁定、删除与排布预览能力。
- 旋转不提供任意改变倾角或抬升高度；坡面内转动保持真实板材尺寸与安装面法向，跨安装面、碰撞、避让和锁区约束由后端校验。
- 归档记录只读；缺少完整目录尺寸和安装模型时不可启用近似拖拽。
- 详细复算使用现有天气数据；缺少某计算链时明确列出。锁定、几何合法或完成清单一致都不等于工程规则全部通过。
- 本轮截图与 HTTP 示例没有调用模型，不构成新的智能体成功率或成本评测；示例也不代表实测项目获批施工。

## 实施边界

| 单元 | 责任与验证 |
| --- | --- |
| `module-transform-geometry.js` | 无 DOM 几何、吸附与角度运算；数值测试及与后端真实角点的差分验证。 |
| `scene-module-transform.js` / `scene.js` | 射线求交、手柄、参考线、指针捕获、OrbitControls 仲裁、资源释放；真实 WebGL 鼠标手势验证。 |
| `design-edit-ui.js` / `app.js` | 工具条、参数、选择、请求失效和明确确认；真实 API 预览／保存／撤销回归。 |
| `manual_modules.py` / `api.py` | 提供真实组件目录契约；所有碰撞、坡面、锁区校验保持后端权威，拒绝时不落盘。 |
| `design_diagnostics.py` / `design-diagnostics.js` | 依据同版本规则与逐组件数据定位问题；只对有明确证据的未锁定对象提供修复预览。 |
| `design_evidence.py` / `design-evidence.js` | 汇总实际文件摘要、输入假设、当前版本校核、审核／导出记录和已记录用量；缺失值不伪造。 |
| `analysis_inputs.py` / `analysis.py` | 输入签名与完整计算清单；发布前核对本次预期文件摘要，原子替换清单，拒绝混写结果。 |

## 验收

- 平顶、金属斜面、多坡屋面的拖拽轮廓与后端候选角点一致，不以二维贴面拉伸替代真实尺寸。
- 真实浏览器完成移动、旋转、吸附、Alt 旁路、Esc 取消、锁板拒绝与锁空白冲突，验证视角不随拖拽误转。
- 预览不落盘，确认生成新版本，撤销恢复几何和锁；详细复算随真实变换更新，旧指标不借用。
- 问题定位只使用对应版本有来源的数据；修复预览显示保留锁定对象，未核对的规则保持未知或未通过。
- 版本证据显示真实文件、完整性状态和缺失项；模型用量不等于人工成本，测试成绩不包装为新的智能体成绩。
- 桌面 Node 全套及与改动相关的 Python、真实 WebGL/DOM 回归完成后，独立审查需求覆盖与边界；记录真实结果和演示截图。
