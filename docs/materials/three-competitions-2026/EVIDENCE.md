# 共用证据清单

## 软件能够提供

- 版本化代码及实际构建的 Windows 安装包、SHA256 和打包输入记录。
- 回归测试结果、完整浏览器流程、安装后运行记录及失败修复说明。
- 四个合成产业案例的输入、用途、来源限制和真实软件计算输出；它们是模拟结果，不是实际发电或客户收益。
- 规则设计步骤、当前版本输入与目录摘要、完成清单、报告、用户批准和导出文件校验。
- 原有 AGH 归档的会话记录可作为历史执行例证；不将其耗时/费用与本轮规则流程混算，也不冒充本轮新模型验证。

具体数量、耗时、通过/跳过与限制只引用[本轮验收记录](../../RELIABILITY_VALIDATION_2026-11.md)，不预填成功率。

## 尚不能由软件验收替代

| 材料 | 当前口径 | 补齐方式 |
| --- | --- | --- |
| 真实客户需求 | 本轮未取得新的访谈/试用证明 | 由本人联系并取得授权，保留日期和原始反馈 |
| 测绘与现场条件 | 泰州四例为合成，存在待核实参数 | 授权图纸、现场尺寸、设备/荷载与接网资料 |
| 独立工程复核 | 内部回归测试不等于独立复核 | 请对应专业人员采用明确口径复核，记录身份和方法 |
| 效率提升 | 不能使用固定99.6%等宣传值 | 同输入与质量要求下记录完整任务、人工和返工 |
| 客户、合同、收入 | 不根据产品完成度推定 | 仅列实际且可授权提交的佐证 |
| 获奖概率 | 无可校准依据 | 不填写或宣传确定百分比 |
| 报名资格 | 团队信息不能由代码核定 | 按赛事原件核对身份、年龄、在泰关系和承诺 |

## 推荐的对照记录字段

任务编号、输入摘要、案例是否真实/授权、复杂度、同条件基线、工具/版本、设备和天气来源、开始结束时间、人工输入工时、复核工时、返工次数、失败原因、关键结果差异、API费用及币种、实际交付物、复核人和局限。

只有输入、目标质量与计算边界可比时才汇总效率或精度。示例脚本应保留失败记录，不能只挑选最好的一次运行。

详见[三项赛事核查报告](../../COMPETITION_RESEARCH_2026-11-04.md)。江苏官方项目表要求 AI 应用方式、完成基础、量化指标及验证数据；OPC 赛道二侧重原型、工作流、录屏和部署；蜂鸟概述覆盖产品/服务、市场、团队、运营与发展。上述对照方法是本项目建议，不是官方指定的样本数或评分权重。
