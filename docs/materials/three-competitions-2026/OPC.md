# 泰州“全球通”杯人工智能 OPC 项目说明

建议赛道：行业轻量智能体开发。高校组/社会组应按本人真实身份和在泰关系选择；材料不代作资格判断。

## 产品与泰州“三市三区”8项分级复盘场景及六维系统性实验实证

光筑把工商业光伏前期方案中重复的卫星底图描边、屋顶建模、约束调整、三维局部重排、8760 小时能量平衡校核和 CAD/PDF/XLSX 材料整理串成一个桌面工作流，目标是让个人或小团队更容易完成可检查的初步交付。除 NREL PVDAQ #2107 公开地面电站（`893.0 kW DC`，2022 年 12 个月共 `3,503` 有效并网小时）站内 POA 驱动无调参盲测（月均 `MAPE = 5.12%`）外，团队已针对泰州市“三市三区”构建按证据强度严格分级的 **8 个复盘场景**（总装机 `7.310 MWp`，几何与设备型号为统一参数化设定：**一级核实公开报道 3 项**——国网泰州供电公司祥泰数智零碳仓库 `552.42 kWp` `[-0.57%]`、海陵区春云路解楼圩约 300m 景观光伏长廊 BIPV `167.61 kWp` `[-1.83%]`、泰州市级机关综合办公楼项目 `1,100 kWp` 不含另案车棚 `[+15.06%，通稿按1,000h整数保守估算]`；**二级待核线索 2 项**——中国医药城 20kV 光电建筑示范项目 `1,276.80 kWp` 并列披露 2013 原报年上网电量 `124.52 万kWh` `[+8.36%]` 与二手摘要预计发电量 `135.00 万kWh` `[-0.05%]`、申源特钢 `1,273.68 kWp` 二手 EPC 摘要线索 `[-0.95%]`；**三级园区典型参数化场景 3 项**——靖江 `1,500.40 kWp` `[-0.28%]`、泰兴 `800.80 kWp` `[-0.36%]`、姜堰 `638.00 kWp` `[-0.85%]`；6 个工业厂房参数化样本均值偏差 `0.51%`，全部 8 项均值偏差 `2.49%`，复现脚本：[`run_comprehensive_experiments.py`](../../../scripts/run_comprehensive_experiments.py)），并在 `projects/taizhou-xiangtai-warehouse` 中生成 `v1 -> v2` 自动规则修复（`S01` 遮挡超限 18 块组件自动剔除，`hard_failed=0`）与同版 DXF/XLSX 交付件。同步完成的六大系统性实验（四链跨倾角一致性均差 `1.73%`；24 任务同条件实跑 M1/M2 单轮 `0.0% (0/18)` → M3 免 Key 本地多轮引擎 `77.8% (14/18)`，并附在线 AGH 历史 3 轮评测归档参考 `94.4% (51/54)`；3D 遮挡阈值 $\tau$ 帕累托寻优；Hanan-Grid A* 正交避障走线节省直流线长 `13.38%`、Shapely 校核穿天井/禁区由 `153 次降至 0 次` 且铝合金缆省造价 `53.54%`；共面单屋面斜拍单应性 1,250 次蒙特卡洛 $\sigma=2\text{ px}$ 误差 `11.75 cm`）全量归档于 [`comprehensive-experiments-2026-11.json`](../../../output/comprehensive-experiments-2026-11.json)。所有对标项目均按三级证据如实标注信息来源与口径边界，不冒充团队已签商业合同。

## 智能体贡献与规则流程

AGH 模型工作流负责理解需求、规划 12 个 MCP 工具调用和处理规则反馈，计算函数负责几何、遮挡、发电、电气、结构与经济数值结果。独立审核只在存在单独审核执行记录时呈现。

本地规则流程与 `#satmap` 卫星图工作台用于无模型 Key 的交互设计与确定性计算。其步骤日志与场址几何标定不是模型思维链或自动视觉分割；关键词指令不是开放式自然语言理解。“四智能体”和“三秒替代设计院”不作为本项目宣传。现场可展示两种模式的入口、必要条件和实际记录，缺少模型配置时只演示规则与交互工作台模式。

## 部署与成本口径

Windows 安装包包含 Python 计算环境和固定版本 AGH；无模型 Key 可使用本地规则设计、三维直接编辑、卫星图工作台及已有记录。新地点的天气与底图可能需要联网；离线能力以已缓存输入与参数化典型气象年兜底为限。安装包版本、体积、哈希和验收环境引用实际构建记录。

一次任务的成本应计入模型账单、计算时间、人工输入、专业复核和返工。仅记录实际存在的费用与耗时；本地不调用模型的流程不能据此宣称总体交付成本为零。销售价格、毛利和获客效率暂作为待验证商业假设。

## 可以直接回答的三个问题

- **AI 与普通脚本的区别是什么？** 项目保留 AGH 模型规划/工具调用路线，并用真实会话举例；本地规则路线按规则执行，两者分开评估。
- **如何防止结果被错误宣传？** 设备代理参数、天气来源、输入假设、版本和未核实项显式呈现；规则检查、独立审核和用户导出批准分别记录。
- **如何验证一个人可以经营？** 记录真实任务中本人所花工时、外部专业复核、计算及模型成本，再验证客户愿付价格；目前不声称已具备设计院全部职能或已盈利。
