# 泰州“全球通”杯人工智能 OPC 项目说明

建议赛道：行业轻量智能体开发。高校组/社会组应按本人真实身份和在泰关系选择；材料不代作资格判断。

## 产品与本地业务

光筑把工商业光伏前期方案中重复的卫星底图描边、屋顶建模、约束调整、三维局部重排、8760 小时能量平衡校核和 CAD/PDF/XLSX 材料整理串成一个桌面工作流，目标是让个人或小团队更容易完成可检查的初步交付。医药洁净厂房、海工车间、文旅坡屋面、农业冷链仓、里下河禽舍、锯齿纺织厂、泰兴化工等演示用于说明不同屋面形态、设备遮挡和负荷条件，全部明确为合成场景，不代表对应企业已经采用。

## 智能体贡献与规则流程

AGH 模型工作流负责理解需求、规划 12 个 MCP 工具调用和处理规则反馈，计算函数负责几何、遮挡、发电、电气、结构与经济数值结果。独立审核只在存在单独审核执行记录时呈现。

本地规则流程与 `#satmap` 卫星图工作台用于无模型 Key 的交互设计与确定性计算。其步骤日志与场址几何标定不是模型思维链或自动视觉分割；关键词指令不是开放式自然语言理解。“四智能体”和“三秒替代设计院”不作为本项目宣传。现场可展示两种模式的入口、必要条件和实际记录，缺少模型配置时只演示规则与交互工作台模式。

## 部署与成本口径

Windows 安装包包含 Python 计算环境和固定版本 AGH；无模型 Key 可使用本地规则设计、三维直接编辑、卫星图工作台及已有记录。新地点的天气与底图可能需要联网；离线能力以已缓存输入与参数化典型气象年兜底为限。安装包版本、体积、哈希和验收环境引用实际构建记录。

一次任务的成本应计入模型账单、计算时间、人工输入、专业复核和返工。仅记录实际存在的费用与耗时；本地不调用模型的流程不能据此宣称总体交付成本为零。销售价格、毛利和获客效率暂作为待验证商业假设。

## 8 分钟路演脚本

| 时间 | 内容 | 屏幕证据 |
| --- | --- | --- |
| 0:00–1:00 | 一个明确的前期方案变更痛点及个人/小团队目标用户 | 同一屋顶的输入条件与需要回答的问题；不虚构访谈 |
| 1:00–2:00 | 模型规划、MCP 工具计算、规则检查与人工确认的分工 | 架构与真实 AGH 执行记录，标出本次演示的模式 |
| 2:00–3:30 | `#satmap` 卫星图多点绘制 C 型/双坡屋顶与禁布区、一键排布、MPPT 配串、四点透视合成与 4 张 CAD 图纸，并转入光筑三维工程库 | 顶点零偏移、走线不穿天井、PVsyst 16 步损耗瀑布图、转入三维工作台保持完整多边形与禁布区 |
| 3:30–5:00 | 在三维工作台演示高低跨/外立面、组件直接拖拽与旋转、区域锁定后局部重排，以及规则 `S01` 问题定位与修复预览 | 锁定组件保留、未锁超限组件预览移除、真实月度图与版本链变化 |
| 5:00–6:00 | 查看同版本报告与版本证据卡，预览并单次批准导出 | 版本、输入签名、PDF 方案书与工程图纸、DXF/XLSX 及 SHA256 回执 |
| 6:00–6:45 | 展示一个不能满足的要求及恢复/撤销过程 | 硬规则失败不会被标通过，不批准导出失败版本 |
| 6:45–7:25 | 安装、离线缓存条件和任务成本账本 | 真实安装验收、运行计时和费用记录的边界 |
| 7:25–8:00 | 泰州试用计划和商业验证方法 | 目标客户类型、授权试用步骤及尚未验证项 |

随后按通知留 3 分钟提问。计算与多方案比较提前完成；只有用同一台机器和同一输入排练并留足余量，才加入现场计算。打开已有结果时说明它是已完成的记录，预录备份说明是录屏；没有模型配置或网络时，不把规则流程说成现场 LLM 推理。

## 可以直接回答的三个问题

- **AI 与普通脚本的区别是什么？** 项目保留 AGH 模型规划/工具调用路线，并用真实会话举例；本地规则路线按规则执行，两者分开评估。
- **如何防止结果被错误宣传？** 设备代理参数、天气来源、输入假设、版本和未核实项显式呈现；规则检查、独立审核和用户导出批准分别记录。
- **如何验证一个人可以经营？** 记录真实任务中本人所花工时、外部专业复核、计算及模型成本，再验证客户愿付价格；目前不声称已具备设计院全部职能或已盈利。
