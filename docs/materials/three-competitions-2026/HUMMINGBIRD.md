# 第十二届蜂鸟青年创客大赛材料草稿

建议领域：科技创新。是否满足年龄、项目拟在泰落地/扩大经营等条件，由参赛人依据盖章通知核实。

## 项目概述（500 字以内）

光筑（蜂鸟青年创客大赛盖章申报书项目全称：**向光而筑——工厂屋顶光伏智能设计系统**）是一款面向工商业屋顶光伏前期方案的 Windows 桌面工具，目标用户是中小光伏 EPC、园区能源服务团队及需要比较改造方案的业主。产品连接卫星图多点描边与比例标定、三维高低跨屋顶建模、组件直接拖拽与区域锁定重排、逐组件遮挡与 8760h 16 步能量平衡仿真、电气 MPPT 配串与荷载规则定位、经济测算，以及 PDF 方案书、4/16 张工程 CAD 图纸和 XLSX 材料清单导出。AGH 模型工作流负责规划并调用 12 个计算工具；无模型 Key 的本地规则与工作台提供可交互的确定性计算。设计、输入签名、分析和导出按版本严格关联，保留未满足要求与待现场核实项。项目除完成 NREL PVDAQ #2107 公开地面电站（`893.0 kW DC`，`3,503` 有效并网小时）无调参盲测（站内 POA 驱动月均 MAPE `5.12%`）外，还完成了泰州市“三市三区”8 项分级复盘场景（总装机 7.310 MWp：含祥泰零碳仓 `-0.57%`、解楼圩约 300m 景观光伏长廊 BIPV `-1.83%`、市级机关综合办公楼 `+15.06%` 等三级明确标注来源边界的参数化对标，6 个工业厂房样本均差 `0.51%`，全部 8 项均差 `2.49%`）及六大系统性实验（四链倾角一致性、24 题消融实跑、遮挡帕累托、Hanan-Grid 正交避障走线节省线长 `13.38%` 与铜铝缆对照、共面单屋面斜拍 1,250 次蒙特卡洛）的全流程复盘验证。前期研发依托在泰已注册企业“泰州市千山一瞬影视科技有限公司”（经营范围含软件开发与技术服务），后续拟设立新能源数字化软件专项事业部，优先在泰州寻找中小光伏 EPC 或园区服务团队开展授权试用，验证按单技术服务或软件订阅模式。真实客户付费订单、营业收入与单位经济性仍待试点验证，项目不替代现场测量和专业工程审核。

## 产品与服务边界

交付内容为前期方案讨论资料：输入说明、计算结果、未满足约束、布置交换文件和材料清单。报价承诺、施工实施、法定或专业审核不因软件生成文件而自动完成，应与合适的专业服务主体明确分工。

## 客户验证与在泰落地计划

1. 邀请目标 EPC/园区团队说明近期真实方案任务，记录常见变更、现有工具、工时和复核方式；尚未进行的访谈标“计划”。
2. 在授权范围内完成试用，逐项记录输入、计算、专业复核、返工与客户反馈，不用合成场景代替试用记录。
3. 比较按项目服务与订阅两种收费方式。价格先通过访谈和小规模试单验证，不沿用未经验证的“199元/单、9800元/年、85%毛利”。
4. 在泰经营方案列出负责人实际可用时间、技术维护、客户沟通和外部专业复核分工；办公、公司登记和合作安排按实际进展填报。
