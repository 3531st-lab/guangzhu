# 江苏“人工智能+住房城乡建设”项目说明草稿

建议赛道：科技创新开放赛道—产业发展。具体以平台可选项和资格审核为准。

## 项目概述

光筑面向工商业屋顶光伏前期方案编制，把屋顶建模、组件排布、遮挡与发电估算、电气及荷载检查、经济测算、方案比较和文件交付连接为可追溯流程。用户可以从模板、自绘屋面或图纸输入开始，调整通道、设备、倾角和容量要求，查看变化后的计算结果与未满足条件。

系统提供两种清楚区分的运行方式：AGH 模型工作流由模型规划并调用工程工具，独立审核有单独会话记录；本地规则流程按确定性步骤计算，不需要模型 Key，不冒充模型推理或独立审核。数值计算由工程工具完成，文件导出需要用户对具体版本确认。

## 要解决的具体问题

前期方案变更会同时影响排布、遮挡、电气、荷载与经济结果；人工跨工具传递时容易混用旧方案和新参数。光筑将设计版本、输入、设备目录、计算完成记录和导出文件关联，通过摘要验证一致性。组件和区域锁定支持在保留已确认布置的前提下局部修改；不能满足的约束会保留问题原因。

以上描述的是产品工作机制。是否减少人工时间、减少错误或提高报价转化率，需要在真实使用中对照验证，不能由测试通过率直接推出。

## 技术路线与实现基础

1. 几何与实景标定：支持多边形屋顶（含 C 型、L 型、高低跨组合厂房）、坡面、障碍物、分段女儿墙、厂房三维外立面及邻楼模型；提供 `#satmap` 卫星底图多点描边、禁布区多边形绘制、米制比例尺标定、近似共面单屋面斜拍照片四点透视配准（Homography，高低跨或多坡屋面须按独立共面坡面分别标定）及一键转入光筑三维工程库。
2. 排布与 8760 小时能量平衡仿真：按条件生成布置，支持三维直接拖拽、旋转、网格/邻板吸附及区域锁定后的局部重排；逐组件遮挡光线追踪，结合 NASA POWER / PVGIS 典型气象年及 Open-Meteo 实时气象（离线时自动回退至本地缓存或参数化 TMY），提供对标 PVsyst 7.x 的 16 步损耗瀑布链（`GlobHor` → `GlobInc` → `GlobEff` → `E_Nom` → `E_Array` → `E_Grid`）、9×9 倾角-方位角寻优矩阵与参数化分位估算（$\sigma=5.22\%$）。
3. 工程与规则问题定位：组串与逆变器 MPPT 配串表校核、C 型/凹多边形屋面内部走线（不跨越天井）、实际铜/铝电缆目录参数、风荷载分区与已实现 35 项规则检查；支持 `S01` 单板遮挡、`E08` 未接线组件、`E10` 直流压降/走线及 `L01` 坡面荷载失败的对象级三维定位与修复预览。
4. 经济：逐时发电与示意用电模型计算自用、上网和限发，保留月度能量平衡以及经济输入来源。
5. 证据与图纸交付：输入及目录指纹、计算完成清单、同版本报告、用户批准后导出 PDF 方案书与工程图纸（[`pdf_generator.py`](../../../backend/guangzhu/report/pdf_generator.py)）、4 张核心分层 CAD 图纸（排布图、组串图、防雷接地图、支架剖面正视大样图 `H1/Y0/Y1/A/X1/X2`，工作台扩展支持 16 张全套工程深化图集）及 XLSX 材料清单，附带文件 SHA256；独立审核与本地规则检查分开。

实现采用 Python/FastAPI、Shapely、pvlib/PySAM、Matplotlib、ezdxf、WebView2/three.js 与 AGH。依赖来源和许可见仓库 `THIRD_PARTY_NOTICES.md`、`data/catalog/PROVENANCE.md`；不能把集成的第三方算法表述为团队原创。

## 应用与推广

优先面向中小光伏 EPC 的前期沟通和方案比选，再验证园区多栋建筑的方案汇总需求。试点步骤是授权数据→共同确定输入→原型试算→专业复核→记录反馈→评估付费意愿。当前没有在本材料中声称已签客户、实际节省比例或确定收入。

本项目定位为前期方案辅助工具。未经现场核实的承载力、消防、并网和报价以待核实事项呈现，不把局部规则通过表述为完整施工批准。
