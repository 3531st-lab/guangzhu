# 光筑 0.3.0 演示操作卡

使用本轮[安装包](../../../dist/guangzhu-setup.exe)，完整 SHA256、测试范围与限制见[验收记录](../../RELIABILITY_VALIDATION_2026-11.md)。公开 GitHub v0.2.0 不包含本轮修复。

## 上台前

1. 提前完成安装和首次启动，等内置组件准备结束。启动和计算都需要实际等待，不能保证几秒完成。
2. 核对四个“泰州产业演示”名称带有“合成”，并展开案例输入与待核实项。确认展示的是演示输入。
3. 至少提前完成一个案例的计算、修改、报告与导出，保留选定版本。方案比较可能耗时数分钟，大型屋顶可能更久，不放进必须按时结束的现场步骤。限时路演优先打开这些已核验版本；若要现场运行，先用同一台机器和同一输入排练并留出余量。
4. 没有模型 Key 时使用“运行本机规则设计（无需模型密钥）”。需要展示 AGH 模型规划时，提前配置并实际验证模型；仅出现入口不代表该路径已通过本轮测试。
5. 保存原速录屏作为备份，播放时说明这是预录。新地点可能需要联网取天气；不要把已有缓存的演示说成所有场景都能断网运行。

## 现场流程

1. **卫星图快速勘测与出图（`#satmap`）**：打开“卫星图设计”，展示干净初始底图，通过多点绘制屋顶外轮廓（如 C 型或双坡厂房）与多边形禁布区，点击“一键铺设”，依次查看气象驱动的最优倾角比选、MPPT 组串分配表、PVsyst 16 步能量平衡瀑布图、斜拍照片四点透视合成+女儿墙视线遮挡，以及 4 张 CAD 图纸（含支架 `H1/Y0/Y1/A/X1/X2` 参数预览），并点击“转入光筑工程库”保存为版本化三维工程项目。
2. **三维工作台精细建模与规则设计**：在合成屋顶或刚转入的项目中，说明尺寸、障碍、承载、电价和负荷输入的来源及假设。运行本机规则设计或打开已核验版本，展示高低跨与厂房三维外观、季节阴影、逐时汇总的月度图和当前版本号。
3. **三维直接操作、锁定局部重排与问题定位**：进入“局部修改”，演示锁定部分屋面/组件后调整其余区域排布，或直接拖拽/旋转单块组件；在“规则”页签点击 `S01` 等问题项的“定位”与“预览移除未锁定超阈值组件”，复算后对照版本变化和材料清单。
4. **版本证据与单次批准导出**：打开“文件”页签查看版本证据卡（SHA256 与输入签名）和同版本报告，先预览导出内容，再点击确认导出。打开生成的 PDF 方案书/工程图纸、DXF 和 Excel，核对版本与设备/电缆内容。
5. **不可行约束与记录回放**：本机规则方案从首页“本机已生成 3D 方案”重新打开；AGH 执行会话从“设计记录”查看。对达不到的约束展示真实失败原因，不把失败方案当作通过。

## 三赛分别强调

- 江苏：建筑输入如何进入计算、约束与结果如何核对、还需要哪些专业复核。
- OPC：个人或小团队怎样完成一次可追溯交付，区分模型规划、确定性计算与人工批准，展示真实时间和费用边界。
- 蜂鸟：拟提供的服务、实际试用与在泰经营计划。没有客户、收入或合作证明的内容保留为待验证计划。

现场遇到异常时，保留报错和项目版本；可切换到已经核验的记录或原速录屏继续讲解，并明确说明切换。不要反复覆盖项目、修改展示数字或伪装现场成功。
